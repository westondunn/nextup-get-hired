# Proposed issue drafts

These files are reviewable drafts, not live work items. The live GitHub issue becomes the
source of truth only after the maintainer explicitly approves publication. When a draft is
published, record the issue number in `docs/WORK_PROGRAM.md` and remove the draft in the same
documentation pull request.

Each draft follows `.github/ISSUE_TEMPLATE/implementation.md`. Do not publish drafts in bulk,
and do not add credentials, personal data, private security findings, or unverified support
claims while turning one into an issue.
